# Trading Performance Analytics Dashboard

My personal BI analytics project built from my Notion trading journal.

## Project Objective

The goal of this project is to transform raw trading journal data into a structured, and visually useful analytics system. It helps analyse my trading performance, risk quality, emotional state, strategy execution, and rule adherence. resulting in better decision making during live trading.

This project is designed for trading performance review as data keeps on stacking from more trades i take weekly.

## Dashboard Pages

### 1. Executive Dashboard
High-level view of total trades, win rate, net RR, profit factor, rule adherence, equity curve, outcome mix, asset performance, and session performance.

### 2. Performance Analytics
Breaks down performance by asset, session, trade model, and direction.

### 3. Behavioral Insights
Analyzes emotional state, mistake type, and rule adherence impact on trading outcomes.

### 4. Risk & Strategy Dashboard
Tracks average risk, largest win, largest loss, confluence quality, and strategy execution.

## Business Value

This dashboard gives me as a trader a clearer view of what is actually driving my performance. It does not only track wins and losses. It also connects performance to behavior, trade selection, market session, risk, and rule adherence.

Acts more like a real BI decision support system than a basic Notion journal.
